## 🎯 What is NeuroCinema?

NeuroCinema visualizes real-time fMRI brain activity predictions as you watch 
a video clip. Select a clip, choose a modality (audio / video / text / 
multimodal), and watch a 3D brain light up — region by region, second by 
second.

Built on top of **TRIBE v2**, a trimodal foundation model for predicting 
fMRI responses to naturalistic stimuli (d'Ascoli et al., 2026, Meta FAIR).

## 🚀 Getting Started

### Prerequisites
- Python 3.11+
- Node.js 20+
- Git

### Quick Start
```bash
# Clone the repository
git clone https://github.com/josegalindo23/neurocinema.git
cd neurocinema

# Backend setup
cd backend
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt

# Frontend setup
cd ../frontend
npm install
npm run dev
```
